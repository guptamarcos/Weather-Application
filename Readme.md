// CSS
--> How to use min-content and max-content properties in CSS.
--> These properties help in controlling the width or height of elements based on their content size.
--> min-content: Shrinks the element to the smallest possible size without overflowing.
--> max-content: Expands the element to fit the full content without wrapping.
